# SecureFPS: End-to-End Localhost Demonstration Script

This document details the exact, step-by-step walkthrough to demonstrate the **Secure Online FPS Game Platform** entirely on `localhost` without requiring an active internet connection.

## 1. Prerequisites & Service Initialization

Ensure MongoDB is running locally (`mongodb://127.0.0.1:27017/`), then start the backend and game server in two separate terminal tabs:

### Terminal 1: Flask Anti-Cheat & Auth Backend
```powershell
cd D:\Secure_Online_FPS_Game_Platform\backend
.\.venv\Scripts\python.exe app.py
```
- **Port:** `5000` (`http://127.0.0.1:5000`)
- **Mode:** Development with real-time SSE stream & scikit-learn Model Pipeline v2 loaded.

### Terminal 2: Authoritative 3D Multiplayer Game Server
```powershell
cd D:\Secure_Online_FPS_Game_Platform\multiplayer-server
node server.js
```
- **Port:** `4001` (`http://127.0.0.1:4001`)
- **Mode:** 30Hz server tick loop, lag-compensation ring buffer, and sliding-window telemetry bridge.

### Terminal 3: Seed Clean Demo Fixtures
```powershell

backend\.venv\Scripts\python.exe scripts/seed_demo.py
```
